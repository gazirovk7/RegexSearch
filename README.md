# RegexSearch — вариант 8

**Студент:** Кориненко Тимофей  
**Группа:** ИС-61  
**Задание:** поиск номера полиса обязательного медицинского страхования (ровно 16 цифр).

## Состав решения
- `RegexSearch.Core` — библиотека классов с моделью результата, состояниями и двумя алгоритмами.
- `RegexSearch.WPF` — графическое приложение WPF.
- `diagrams` — граф конечного автомата и блок-схема.
- `test-data.txt` — 5 корректных и 5 некорректных тестовых строк.
- `Отчет.docx` — пояснительная записка.

## Требования
Windows 10/11, Visual Studio 2022 с workload «Разработка классических приложений .NET», .NET 8 SDK.

## Запуск
1. Откройте `RegexSearch.sln` в Visual Studio 2022.
2. Убедитесь, что проект `RegexSearch.WPF` выбран запускаемым (Set as Startup Project).
3. Соберите решение (Build → Build Solution).
4. Запустите F5.
5. Введите текст и проверьте кнопки «Поиск через Regex», «Поиск через автомат» и «Сравнить алгоритмы».

## Регулярное выражение
`(?<![A-Za-zА-Яа-яЁё0-9_])[0-9]{16}(?![A-Za-zА-Яа-яЁё0-9_])`

Распознаёт ровно 16 ASCII-цифр, не являющихся частью более длинного буквенно-цифрового идентификатора. Позиция в результатах отсчитывается с нуля.
